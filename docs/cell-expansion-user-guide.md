# 小区扩容工单使用说明

## 适用场景

已安装、已开通、维护中的站点，从 `3 扇区 / 3 小区` 扩到 `3 扇区 / 6 小区` 时，使用「小区扩容」工单。当前系统只允许状态为 `pending_online`、`online_pending_activation`、`operational`、`maintenance` 的站点创建小区扩容工单。

这里的“扩容”不是把物理扇区从 3 个改成 6 个，而是在原有 3 个扇区下新增小区/设备。例如 LCID 从 `1/2/3` 扩到 `1/11/2/12/3/13`，系统会识别为 3 个物理扇区、6 个小区。

未安装、未开通的站点不需要创建小区扩容工单，直接在站点规划里导入或编辑目标 LLD。新建工单时选择「小区扩容」后，站点下拉只会展示安装后的站点。

## 操作原则

已开通站点不要直接修改当前规划。先创建「小区扩容」工单，准备完整目标 LLD，由系统在扩容完成后自动切换规划。

这样做的原因是：扩容施工前，现网实际仍是原 `3 扇区 / 3 小区`。如果提前把当前规划改成 `3 扇区 / 6 小区`，OMC 和检查流程会把尚未安装的新小区/设备判断为异常，影响审核和站点状态判断。

## 一、准备目标 LLD

1. 在新建工单面板点击「准备目标 LLD」。
2. 在弹窗里点击「下载底稿」。底稿来自站点当前 LLD。
3. 在底稿中保留已有小区，并新增扩容后的小区/设备。
4. 原有小区不要修改关键字段，例如 `local_cell_id`、`PCI`、频点、带宽、`ECI/NCI` 等。
5. 上传完整目标 LLD，不要只上传新增小区。
6. 查看差异预览，例如：当前 `3 扇区 / 3 小区` -> 目标 `3 扇区 / 6 小区`，新增 3 个小区/设备。
7. 确认无误后点击「使用此目标 LLD」。

注意：不要先去修改站点当前规划。系统会在扩容完成后自动合并目标 LLD。

## 二、创建小区扩容工单

1. 进入 Web 管理端。
2. 打开「工单管理」。
3. 点击「新建工单」。
4. 选择要扩容的站点。选择「小区扩容」后，下拉只显示待上线、已上线待激活、运营中、维护中的站点。
5. 工单类型选择「小区扩容」。
6. 选择开站检查模板。系统会优先默认选中该站点最近一次有效开站工单实际使用过的模板；如果没有历史模板，再按当前模板绑定规则推荐。生产库没有模板绑定记录时，系统会回退展示已有检查模板，避免下拉为空。
7. 点击「准备目标 LLD」，按上一节完成底稿下载、完整 LLD 上传和差异预览。
8. 填写执行人、标题、优先级等信息。
9. 提交工单。

小区扩容复用开站检查模板，但系统只会生成新增小区/设备相关的检查项，不会要求重新检查原有小区。

如果上传失败，通常是以下原因：

- 该站点没有当前规划。
- 该站点还未安装或仍处于施工中。
- 该站点已有未完成的小区扩容工单。
- 目标 LLD 删除了原有小区。
- 目标 LLD 修改了原有小区关键字段。
- 目标 LLD 没有识别出新增小区。

## 三、施工人员执行工单

1. 施工人员在移动端查看「小区扩容」工单。
2. 接受工单。
3. 按系统生成的检查项安装新增设备。
4. 对新增设备扫码绑定 SN。
5. 完成现场检查并提交。

系统只会跟踪新增小区/设备，不会要求施工人员重新检查原有 `3 扇区 / 3 小区`。

## 四、后台审核与 OMC 确认

1. 审核人员进入工单详情。
2. 查看新增小区/设备的绑定和 OMC 状态。
3. 审核通过后，工单进入 OMC 激活确认阶段。
4. 系统只检查新增小区/设备是否在 OMC 上激活，不会用目标 LLD 误判原有站点。
5. 当新增小区/设备全部曾经激活后，系统自动完成扩容工单。

如果 OMC 数据延迟或接口没有及时同步，可以在工单里使用手动 OMC 确认。手动确认只能确认本次扩容新增目标对应的 SN。

## 五、扩容完成后的系统行为

扩容工单完成后，系统会自动把目标 LLD 合并为站点当前规划。

阶段变化如下：

- 扩容施工前：当前规划仍是原 `3 扇区 / 3 小区`，避免误报。
- 扩容施工中：工单只跟踪新增小区/设备。
- 扩容完成后：当前规划变成目标 `3 扇区 / 6 小区`。

## 常见问题

### 未安装站点是否需要创建小区扩容工单？

不需要。未安装站点没有现网状态需要保护，直接导入或编辑目标 LLD 即可。

### 目标 LLD 是否只上传新增三个小区？

不建议。目标 LLD 应该是扩容完成后的完整规划，包含原有小区和新增小区。系统会自动识别新增小区/设备。

### 原有小区的信息能否顺手修改？

不能修改关键字段。小区扩容解决的是新增小区/设备上线，不是原有小区重规划。如果确实需要调整原有小区配置，应先确认业务流程，再走对应的规划变更方式。

### 为什么工单完成前不直接修改当前规划？

因为当前规划会影响 OMC 校验和站点状态判断。提前改成目标 LLD 会让系统认为新增小区/设备已经应该存在，导致施工前或施工中出现误报。
