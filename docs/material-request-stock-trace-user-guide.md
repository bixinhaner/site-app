# 物料申请与出入库记录关联使用说明

## 这次更新解决什么问题

以前用户要确认一张物料申请最终有没有出库、有没有退库，通常需要在多个页面之间来回查单号。现在系统会把物料申请、领料单、出库单、退库单串起来。

更新后，可以按这条链路追溯：

```text
物料申请单 -> 领料单 -> 出库单 -> 退库单
```

用户不需要手工关联。只要出库或退库是从物料申请流程产生的，系统会自动带出来源申请单和来源领料单。

## 哪些人会用到

- 申请人：确认自己申请的物料是否已经出库、是否还有退库记录。
- 仓库人员：处理出库、退库收货时，确认当前单据来自哪张申请。
- 管理人员：在 Web 端按申请单号、领料单号或出入库单号追溯完整记录。
- 财务/审计/运营：核对一张申请对应的实际出入库流水。

## Web 端怎么用

### 1. 在出入库记录里查来源申请单

路径：

```text
Web 管理端 -> 库存管理 -> 出入库记录
```

现在列表会显示来源申请单号。通过物料申请流程产生的出库记录，以及基于该出库记录产生的退库记录，都会带上来源信息。

可以搜索：

- 申请单号
- 领料单号
- 出库单号
- 退库单号
- 其他原有支持的关键字

适合用来回答：

- “这张申请到底有没有出库？”
- “这张退库单是退哪张申请的物料？”
- “我只有申请单号，能不能查到所有出入库记录？”

### 2. 在申请单详情里看关联出入库记录

路径：

```text
Web 管理端 -> 库存管理 -> 物料申请 -> 申请单详情
```

申请单详情新增了“关联出入库记录”。进入后可以直接看到这张申请产生的出库和退库记录。

如果需要继续查看明细，可以从这里跳到：

- 领料单详情
- 出入库历史

推荐用法：

1. 先打开申请单详情。
2. 看“关联出入库记录”里是否有出库或退库。
3. 如果数量有疑问，再进入对应出入库记录看具体物料和 SN。

## App 端怎么用

### 1. 申请人查看自己的申请进度

路径：

```text
App -> 物料申请 -> 申请详情
```

申请详情现在会显示“关联出入库记录”。这里可以看到该申请产生的出库单、退库单、数量、仓库、操作人和时间。

如果关联记录来自某张领料单，可以点进领料单详情继续查看。

适合现场人员快速确认：

- 申请是否已经出库。
- 还有没有退库记录。
- 这次出入库数量大概是多少。

### 2. 仓库人员处理退库收货

路径：

```text
App -> 退库收货
```

退库收货批次列表中，每张退库单会显示：

- 关联出库单
- 来源申请单
- 来源领料单

进入收货详情后，也会继续显示来源申请单和来源领料单。

这样仓库人员在收货前就能确认：

- 当前退库来自哪张物料申请。
- 当前退库对应哪张领料单。
- 是否和现场交回的物料说明一致。

### 3. App 退库收货搜索

路径：

```text
App -> 退库收货 -> 搜索框
```

现在可以按以下内容搜索：

- 退库单号
- 出库单号
- 申请单号
- SN

如果现场只报了申请单号，仓库人员也可以直接在退库收货里搜索。

## 推荐操作方式

### 场景一：用户问“我的申请有没有出库？”

1. 打开 Web 或 App 的物料申请详情。
2. 查看“关联出入库记录”。
3. 如果有出库记录，说明该申请已经产生出库。
4. 如果还有退库记录，继续看退库状态和数量。

### 场景二：仓库收到退回物料，需要确认来源

1. 打开 App 的“退库收货”。
2. 搜索退库单号、出库单号、申请单号或 SN。
3. 在退库单卡片上确认来源申请单和来源领料单。
4. 进入收货详情后，再核对实际退回物料。
5. 确认无误后执行收货；不一致时先暂停处理并核对原因。

### 场景三：管理人员要查完整链路

1. 在 Web 端进入“出入库记录”。
2. 用申请单号或领料单号搜索。
3. 查看该申请下所有出库和退库记录。
4. 需要看物料明细时，进入对应记录详情。

## 查不到来源时怎么办

如果某条出入库记录没有显示来源申请单，通常是以下情况：

- 这笔出入库不是从物料申请流程产生的，例如快速出库、手工调整、历史手工入库。
- 这张单据本身没有领料单或申请单来源。
- 录入时走了旧流程或非标准流程。
- 用户没有权限查看对应仓库或申请单。

处理建议：

1. 先确认是否使用了物料申请流程。
2. 再用出库单号、退库单号或 SN 搜索。
3. 如果仍然查不到，联系管理员核对该单据的创建来源和权限范围。

## 注意事项

- 来源关联是系统自动生成的，不需要用户手动填写。
- 只有通过物料申请流程产生的出库、退库，才会完整显示申请单和领料单来源。
- App 端需要更新到包含本次改动的版本后才能看到新字段。
- Web 端和 App 端显示的是同一套业务链路，只是入口不同。
- 如果用户没有某个仓库或申请单的查看权限，页面仍会按权限范围隐藏相关数据。

## 一句话总结

以后查物料流向，优先从申请单号开始查。Web 用“出入库记录”和“申请单详情”，App 用“申请详情”和“退库收货”，系统会自动把申请、领料、出库、退库串起来。
